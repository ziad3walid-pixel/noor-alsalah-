# تطبيق نور الصلاة

تطبيق يساعد المسلمين على:
- قراءة القرآن الكريم والاستماع للتلاوات
- معرفة مواقيت الصلاة
- تحديد اتجاه القبلة
- الاستماع للأذان
- التذكير بالصلاة على النبي ﷺ

## المميزات
- مواقيت صلاة دقيقة
- بوصلة قبلة
- قرآن كامل مع تلاوات
- إشعارات الأذان

## التثبيت
التطبيق حالياً تحت التطوير.

## المساهمة
أي اقتراحات أو تعديلات مرحب بيها.
